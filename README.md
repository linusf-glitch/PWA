# Sizeless PWA

Mobile-first web app for Sizeless (adjustable kids' shoes): foot scan, size and setting colour, buy via Shopify, growth chart, WhatsApp fit checks, rescan, share/gift/referral.

- Start with [CLAUDE.md](CLAUDE.md) and [docs/progress.md](docs/progress.md).
- Full background: [docs/handoff.md](docs/handoff.md).
- Work plan: [docs/backlog.md](docs/backlog.md).

## Run it locally

Needs Node 22.

```
npm install
npm run dev
```

Other commands are listed in [CLAUDE.md](CLAUDE.md#commands).
